# Appliance Meter development

Keep changes scoped to this integration. Preserve existing appliance identities,
configuration, decimal accounting totals, and source baselines unless a task
explicitly authorizes changes. Run relevant backend and frontend tests.

Do not deploy, reload, restart Home Assistant, or publish this repository without
explicit authorization. Tests must use temporary Home Assistant instances and
synthetic fixtures; never connect to a private installation.

License choice and public repository ownership require maintainer approval.
